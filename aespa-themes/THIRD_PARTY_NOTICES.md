# Third-party notices

The icon themes include a small number of marks adapted from open-licensed icon sets. Each glyph file under `src/icons/glyphs/items/` records its origin in a `source` field; the rest are original.

- **Material Design Icons** by Pictogrammers (https://pictogrammers.com/library/mdi/), licensed under the Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0). Adapted marks are rescaled path outlines.
- **Cormorant Garamond** by Christian Thalmann (https://github.com/CatharsisFonts/Cormorant), licensed under the SIL Open Font License 1.1. The `æ` ligature outline on the root folder is extracted from the 600 Italic.

No marks are taken from Phosphor Icons or Tabler Icons in the current build; the import script supports them (MIT) and any future use should be listed here.
